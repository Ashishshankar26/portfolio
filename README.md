# Ashish Shankar — Portfolio

Minimal black-and-white developer portfolio built from GitHub data for [@Ashishshankar26](https://github.com/Ashishshankar26).

## Features
- Strict monochrome Light/Dark polarity toggle (`I` key or header button)
- Featured flagships (`ALMS`, `ClubPulse`, `CivicLens`, `FreelanceHub`)
- Filterable & searchable archive of 14+ public GitHub projects
- Command Palette (`Ctrl+K` / `/`) and Project Specs modal
- Zero-dependency static HTML5, CSS3, and Vanilla JS
